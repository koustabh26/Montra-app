# Support

Montra is maintained on a best-effort, volunteer basis. There is no guaranteed response time.

- **Questions / how-to:** read the [FAQ](docs/FAQ.md) and [docs](docs/), then open an issue using the *Question*-style link on the issue chooser or, if the maintainer enables GitHub Discussions, a discussion.
- **Bugs:** open an issue with the *Bug report* template.
- **Feature requests:** open an issue with the *Feature request* template.
- **Security problems:** do not use public issues; see [SECURITY.md](SECURITY.md).

When asking for help, include your Android version, device model, and app version (Settings → About, or the commit you built).

Never post your PIN, backup files or any personal financial data in an issue.
